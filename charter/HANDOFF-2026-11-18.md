## 6. Recipes and gotchas

- **Guard before every commit to main:** `./target/debug/xtask guard`. Read its exit code directly, never through a pipe. The guard denylists private project names and client names in committed files, so write generic names.
- **xtask gates the repository it was built in.** Read the commit in the gate log's first line.
- **Every gate re-clones fresh** and checks the clone's HEAD equals the commit under test (three wasted gates came from stale clones).
- **Mac discipline:** the head Mac is shared. Run only with a grant, at nice 15, at most 4 jobs, with START/END lines, one run at a time. A run starts on an explicit GO naming the commit and the limits; READY is not GO.
- **Linux route:** the local Tart VM `holden-mcp-linux` (`tart ip holden-mcp-linux`), at most 4 CPUs and 8 GB when granted. Stop it when done.
- **The former Boat machine is retired and untrusted.** Its SSH host key changed twice on 2026-11-17 and it is no longer in the Boat account. Never accept a changed host key without an independently announced rebuild.
- **`real_repo` tests need a private seed** (`HOLDEN_E2E_REAL_REPO`, or `e2e/real-repo` under the private root). The seed is a clone of a private client repository; it never leaves the owner's machines.
- **Watch board lines by field, not by word.** A release line is one whose seat holds the matching START and whose state begins END or MAC RELEASED. Matching on words gave four false triggers in two days.
- **cmux:** address seats as `surface:<id>`; a bare number fails. `send` refuses when a prompt holds text; use `--force` only after reading the screen.
- **Never print** 32-hex values, API keys, the owner's email, or any absolute home-directory path. Write `~/`.
- **Every `rm`** takes a literal path or `${var:?}`, never a glob.
