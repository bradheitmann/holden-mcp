# SYNTHETIC planning document: Field Notebook

This is an invented project used only as a test fixture. The product,
its owner and every promise below are synthetic.

## What it is

Field Notebook is a small note-taking product. People write notes on a
phone or a laptop; agents read and file notes through a public API.

## Promises

The owner's words, one per line. Each line that starts with the promise
marker states exactly one promise.

- PROMISE: A saved note is never lost, even if the app closes halfway through saving.
- PROMISE: When an export fails, the person sees why it failed and how to retry.
- PROMISE: An agent can list every note through the public API without reading the screen.
- PROMISE: Deleting a note asks for confirmation before anything is removed.

## Not promises

Ideas the owner has not committed to are not promises, for example an
undo button or an offline mode. They are listed here only so a reader can
see that they are not marked as promises.
